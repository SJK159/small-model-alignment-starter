\section{Limitations and Reproducibility}
\label{sec:limitations}

\begin{itemize}
    \item Single seed (42) for all experiments; results may not generalize.
    \item Judge model bias: \texttt{gemini-3.6-flash} may systematically prefer certain response styles.
    \item Small evaluation sets (300 prompts each).
    \item Kaggle T4 GPU memory constraints may have limited batch sizes.
    \item Single-turn evaluation only.
\end{itemize}

\textbf{Reproducibility:} All code, configs, and metrics are in the GitHub repository. Training scripts log full hyperparameters to \texttt{config.json}. Metrics are saved as JSONL files after every evaluation step.
